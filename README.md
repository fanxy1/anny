# anny

在 Mac 上看 Tailscale 里的服务器：资源占用、进程，以及一键打开 SSH 终端。

![anny](docs/anny.png)

演示界面，主机名和地址是虚构的。

## 它做什么

把常用机器放进左侧名单。点一台，在 **资源 / 进程 / 终端** 之间切换。

- **名单**：从本机 Tailscale 节点里勾选加入，也可以手填主机名。只记在 anny 里，不会改 Tailscale。
- **资源**：点「刷新」读取系统、CPU（核数和线程数）、内存、Swap 和磁盘。打开「动态」持续刷新。换一台机器不会自动拉数据。
- **进程**：切到这一页会自动读取。可搜索（逗号表示或）、点列名排序、钉在顶部；选中后可结束进程。打开「动态」看瞬时 CPU。`⌘F` 搜索当前列表。
- **终端**：点「连接」或双击名单。`⌘T` 连接，`⌘D` 断开。
- **备注**：有备注时名单显示备注，方便认出是哪台。

移出名单只是 anny 不再盯它，节点还在。

## 使用前

- macOS 14 或更新
- 本机已安装并登录 [Tailscale](https://tailscale.com/download)
- 能用密钥免密 SSH 到目标机器（Linux）
